Como funciona a pesquisa externa?

O HTML não pesquisa automaticamente toda a internet nem gera respostas de IA por conta própria. Para ativar esse recurso, configure abaixo a URL de um backend que consulta fontes permitidas e um modelo de IA. A chave secreta deve ficar no servidor, nunca no navegador.

Sem endpoint, a busca local funciona sobre o conteúdo cadastrado neste arquivo.

Metodologia

Fontes, citações e rigor

1. Dado textual
O que a passagem bíblica ou o documento consultado efetivamente afirma. Identifique tradução, referência e, quando necessário, variante textual.
2. Contexto e evidência
Dados linguísticos, literários, históricos e documentais, com fontes identificáveis.
3. Inferência teológica
Conclusão construída a partir das evidências. Explique a ligação lógica e não a apresente como citação direta do texto.
4. Questões em debate
Apresente as principais interpretações concorrentes, seus argumentos e limites. Diga quando a evidência disponível não permite conclusão segura.

Regras para as fontes

  • Priorizar fontes primárias, universidades, periódicos científicos, editoras acadêmicas e repositórios de acesso aberto.
  • Não inventar autores, citações, páginas, edições, datas ou links.
  • Distinguir citação literal, paráfrase, inferência e síntese do aplicativo.
  • Quando o texto integral de uma obra não estiver acessível, declarar essa limitação.
  • Respeitar licenças, direitos autorais, privacidade e limites dos serviços consultados.
Integração técnica

Configurar serviço externo

Informe o endereço do seu backend, se já tiver um. A URL fica guardada apenas nesta sessão; este protótipo não armazena chaves secretas.

Contrato esperado do backend

O frontend envia uma requisição POST em JSON com query, category, depth, mode e context. O backend deve responder JSON com answer e, opcionalmente, sources — uma lista de objetos com title, url, author e publishedAt.

Configure CORS, autenticação, limites de uso e validação de entradas no servidor. Não insira API keys de provedores neste HTML.
